The Problem with Shared Clusters

Teams sharing a Kubernetes cluster for AI experiments face critical challenges:

  • CRD Collisions: Custom Resource Definitions conflict across experiments, breaking reproducibility
  • GPU Starvation: Unquoted workloads starve other jobs, making it impossible to predict resource availability
  • False Isolation: Namespaces provide logical boundaries, but not true isolation or independent control planes
  • State Pollution: Previous experiments leave artifacts, affecting new runs
  • Team Context Switching: Developers spend time managing cluster access instead of running experiments

The Solution: Ephemeral, Isolated Clusters

Ghostcluster creates a dedicated Kubernetes cluster for each experiment, PR, or notebook using vCluster—lightweight virtual clusters that share the host kernel but maintain complete isolation.

Each cluster is ephemeral: It lives as long as your experiment and automatically tears down with no manual cleanup. No CRD conflicts, no GPU starvation, no state pollution. Just pure, isolated compute for every experiment.

Ghostcluster handles the complexity. You focus on your models.

Key Features

⏱️

Auto-Cleanup with TTL

Clusters automatically expire and tear down after a configurable TTL. No orphaned resources, no surprise bills.

🎯

GPU Quotas & Scheduling

Reserve and guarantee GPU access for each experiment. No job starvation, predictable resource allocation.

🔒

Isolated Network & Storage

Each cluster has its own network policies and persistent volumes. Complete data isolation by default.

📋

Templates & Presets

Define cluster templates for different workload types (LLM training, inference, data processing) for consistency.

🚀

Git & PR Integration

Spin up a cluster per PR with one comment. Tight integration with your CI/CD and Git workflows.

Quick Start: One Command

Get a fully isolated Kubernetes cluster with GPU in seconds:

$ ghostctl up --gpu 1 --ttl 4h Cluster Name: exp-gpt-finetune-2025 Control Plane: 192.168.1.42:6443 Kubeconfig: ~/.kube/ghostcluster-exp-gpt-finetune.yaml GPU Reserved: 1x NVIDIA A100 Network: 10.20.0.0/16 TTL: 4 hours (expires 2026-02-10 10:15 PM) ✓ Cluster ready in 8 seconds ✓ kubectl configured

Then deploy your workloads. Cluster auto-cleans when TTL expires.
